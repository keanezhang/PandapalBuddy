# PRD · 博客系统

> 版本：v1.0 | 日期：2025-01-15 | 复杂度：复杂

---

## 一、概述与背景

##### 背景
当前缺乏一个统一的自有博客平台：作者无法沉淀长期内容，读者缺少稳定的优质内容入口，互动仅停留在阅读层面。依赖第三方平台受限于规则与广告分成，自建成本高且维护难，评论互动与内容治理能力薄弱。

##### 目标
- 目标 1：上线 12 周内注册用户达到 10,000，月活跃读者达到 5,000
- 目标 2：上线 12 周内周均发布文章 ≥ 200 篇，篇均评论数 ≥ 3
- 目标 3：评论审核闭环，违规内容 24 小时内处理率 ≥ 99%
- 目标 4：核心接口可用性 ≥ 99.9%，注册/登录/发布/评论链路错误率 < 1%

##### 角色清单

| 角色 | 职责 | 核心诉求 |
|------|------|---------|
| 读者 | 注册登录、浏览文章、发表评论与回复、点赞 | 快速找到并阅读好内容，顺畅参与互动 |
| 作者 | 在读者能力之上，创作、编辑、发布、下线自己的文章 | 内容能被看到，创作流程顺畅、不丢稿 |
| 管理员 | 内容审核（文章/评论）、用户治理（封禁/解封）、平台数据监控 | 平台内容合规、环境干净、数据可观测 |

> 角色关系：作者 = 读者 + 创作权限（角色升级）；管理员为平台治理角色，可对全部内容操作。

##### 场景清单

### 场景 1：新用户注册登录（核心）
- **发生时态**：首次
- **角色**：读者 / 作者
- **目标**：用邮箱注册账号并完成登录，进入首页开始浏览
- **前置条件**：无账号、网络可用；注册需邮箱未被占用

### 场景 2：浏览与阅读文章（核心）
- **发生时态**：日常
- **角色**：读者 / 作者 / 管理员
- **目标**：通过首页文章流、分类/标签、搜索找到文章并完整阅读、点赞
- **前置条件**：无需登录即可浏览；文章状态为"已发布"

### 场景 3：发布与编辑文章（核心）
- **发生时态**：日常
- **角色**：作者
- **目标**：创作文章、保存草稿、最终发布上线；后续可编辑或下线
- **前置条件**：已登录且具备作者角色；编辑器支持富文本与自动保存

### 场景 4：评论与回复（核心）
- **发生时态**：日常
- **角色**：读者 / 作者
- **目标**：对文章发表评论、回复他人评论、删除自己的评论
- **前置条件**：已登录；评论功能对该文章开启

### 场景 5：内容审核（边缘）
- **发生时态**：日常
- **角色**：管理员
- **目标**：审核待处理评论/文章，处置违规内容
- **前置条件**：存在待审核内容；管理员已登录后台

### 场景 6：未登录/越权操作（边缘）
- **发生时态**：异常
- **角色**：读者 / 作者
- **目标**：尝试评论、创作或编辑他人文章时被正确拦截并引导登录
- **前置条件**：未登录，或登录角色不匹配所需权限

### 场景 7：热门文章高并发（边缘）
- **发生时态**：峰值
- **角色**：读者
- **目标**：热门文章被大量同时阅读、评论时，页面正常打开、评论不丢失
- **前置条件**：文章阅读/评论量突增（如被外部分享）

##### 场景-角色矩阵

| 场景 | 角色 | 核心/边缘 | 发生时态 |
|------|------|----------|---------|
| 新用户注册登录 | 读者/作者 | 核心 | 首次 |
| 浏览与阅读文章 | 读者/作者/管理员 | 核心 | 日常 |
| 发布与编辑文章 | 作者 | 核心 | 日常 |
| 评论与回复 | 读者/作者 | 核心 | 日常 |
| 内容审核 | 管理员 | 边缘 | 日常 |
| 未登录/越权操作 | 读者/作者 | 边缘 | 异常 |
| 热门文章高并发 | 读者 | 边缘 | 峰值 |

### 3.3 状态流转

#### 文章状态机

```text
      ┌──────────┐   提交发布     ┌──────────┐   作者下线/管理员强制下线   ┌──────────┐
 ────►│  草稿     │ ────────────► │  已发布   │ ────────────────────────► │  已下线   │
      └──────────┘               └─────┬────┘                          └──────────┘
                                       │ 重新发布
                                       ▼
                                 ┌──────────┐
                                 │  已发布   │
                                 └──────────┘
```

##### 状态定义

| 状态 | 含义 | 允许的下一状态 | 触发迁移的动作/条件 |
|------|------|---------------|-------------------|
| 草稿 | 仅作者可见，可编辑，未对外展示 | 已发布 | 作者提交发布且通过基础校验 |
| 已发布 | 对所有读者可见，可被搜索/评论 | 已下线 | 作者主动下线，或管理员强制下线违规文章 |
| 已下线 | 不对读者展示，内容保留，可重新发布 | 已发布 | 作者重新发布，或管理员解除处置 |

##### 非法迁移

| 从 | 到 | 拒绝原因 | 系统行为 |
|----|-----|---------|---------|
| 草稿 | 已下线 | 未发布内容无需下线 | 拒绝并提示"请先发布" |
| 已下线 | 草稿 | 下线不等于撤回编辑，避免状态回退混乱 | 拒绝并提示"请重新发布" |

#### 评论状态机

```text
      ┌──────────┐   提交（开启审核）   ┌──────────┐   审核通过   ┌──────────┐
 ────►│  待审核   │ ──────────────────► │  已通过   │ ──────────► │  展示中   │
      └──────────┘                     └─────┬────┘             └──────────┘
                                             │ 审核拒绝/作者或管理员删除
                                             ▼
                                       ┌──────────┐
                                       │ 已拒绝/已删除（终态）│
                                       └──────────┘
```

> 关闭审核时：提交后直接进入"已通过"。

##### 状态定义

| 状态 | 含义 | 允许的下一状态 | 触发迁移的动作/条件 |
|------|------|---------------|-------------------|
| 待审核 | 提交后等待管理员审核，仅提交者自己可见 | 已通过, 已拒绝 | 管理员审核通过/拒绝 |
| 已通过 | 公开展示在评论区 | 已删除 | 作者删除自己的评论，或管理员删除违规评论 |
| 已拒绝 | 违规评论被驳回，不展示 | — | — |
| 已删除 | 从公开区移除 | — | — |

##### 非法迁移

| 从 | 到 | 拒绝原因 | 系统行为 |
|----|-----|---------|---------|
| 待审核 | 已删除 | 待审核状态不允许直接删除，需先审核 | 提示"评论待审核，无法删除" |
| 已拒绝 | 已通过 | 已拒绝的评论不可复活，避免绕过审核 | 拒绝操作 |

### 3.4 数据字典

> 字段级契约，供研发直接编码。

#### 用户（user）

| 字段名 | 类型 | 必填 | 约束/取值域 | 业务含义 | 来源 |
|-------|------|-----|-------------|---------|------|
| user_id | bigint | ✅ | 自增主键 | 用户唯一标识 | 系统生成 |

| password_hash | string | ✅ | bcrypt，长度 60 | 加密后的密码 | 系统生成 |
| nickname | string | ✅ | 长度 1~20，去首尾空格 | 展示昵称 | 用户输入 |
| avatar_url | string | ❌ | URL，长度 ≤ 255 | 头像地址 | 用户输入/对象存储 |
| role | enum | ✅ | reader / author / admin | 角色 | 系统生成（注册默认 reader） |
| status | enum | ✅ | normal / banned | 账号状态 | 系统生成 |

- 所有主键 ID 用 `xxx_id`；外键用语义名（`author_id`、`article_id`、`user_id`）

**跨对象引用**：

## 四、需求详细描述

### 4.1 背景与目标

承接第一章概述：构建自有博客平台，打通"注册登录 → 创作发布 → 阅读互动 → 审核治理"完整闭环。本期聚焦三个核心能力：账号体系、文章创作与浏览、评论互动，并配套管理员审核治理。

##### 本期范围
- ✅ 包含：邮箱+密码注册/登录/找回密码；文章草稿/发布/下线/删除；富文本编辑与自动保存；文章列表/详情/分类/标签/搜索；评论/回复/删除自己的评论；管理员评论审核与文章处置；用户封禁/解封；基础数据统计；文章/评论点赞（P2）
- ❌ 不包含：第三方登录、移动端 App、站内私信、打赏、订阅推送、SEO 优化、多语言

### 4.2 用户故事

#### Story 1：注册并登录（P0）
- **作为** 新读者
- **我希望** 用邮箱注册账号并通过邮箱+密码登录
- **以便** 保留我的身份，后续能发表评论、参与互动
- **没有这个功能，用户会怎样？** 无法参与互动，内容消费为纯游客模式，无法沉淀用户资产
- **优先级**：P0

#### Story 2：创作并发布文章（P0）
- **作为** 作者
- **我希望** 在创作中心撰写文章、自动保存草稿，确认后一键发布
- **以便** 我的内容能公开被读者阅读
- **没有这个功能，用户会怎样？** 平台无内容供给，产品失去核心价值
- **优先级**：P0

#### Story 3：发表评论与回复（P0）
- **作为** 读者
- **我希望** 在文章详情页发表评论、回复其他读者的评论，并能删除自己的评论
- **以便** 与作者和其他读者互动交流
- **没有这个功能，用户会怎样？** 平台沦为单向内容站，互动价值缺失
- **优先级**：P0

#### Story 4：评论审核与处置（P1）
- **作为** 管理员
- **我希望** 在管理后台审核待处理评论，通过或拒绝，并可删除违规评论
- **以便** 过滤垃圾与违规内容，维护评论区环境
- **没有这个功能，用户会怎样？** 评论区被广告/违规内容污染，影响读者体验与合规
- **优先级**：P1

#### Story 5：管理自己的文章（P1）
- **作为** 作者
- **我希望** 在文章管理页查看草稿与已发布文章，编辑、下线或删除
- **以便** 持续维护我的内容，修正错误或撤回不当内容
- **没有这个功能，用户会怎样？** 内容发布后无法修正，作者体验受损
- **优先级**：P1

#### Story 6：封禁违规用户（P2）
- **作为** 管理员
- **我希望** 封禁发布违规内容的用户，并可解封
- **以便** 处置恶意用户，保护平台秩序
- **没有这个功能，用户会怎样？** 恶意行为无法遏制，治理成本上升
- **优先级**：P2

### 4.3 功能清单

> 微交互四步法：触发 → 反馈 → 规则 → 循环。

#### 4.3.1 用户注册登录（账号域·注册登录 / 账号安全）

##### 1. 邮箱注册

| 四步 | 说明 |
|------|------|
| **触发** | 未登录用户进入注册页，填写邮箱、密码、昵称，点击"注册"；前置：邮箱未被占用 |
| **反馈** | 提交后按钮 loading；成功即自动登录并跳转首页，顶部显示"欢迎，{昵称}" |
| **规则** | 邮箱格式校验；邮箱全局唯一；密码 ≥ 8 位且含字母+数字；昵称 1~20 字；需通过邮箱验证码（5 分钟有效） |
| **循环** | 成功后会话建立，可继续浏览；注册页关闭 |

##### 2. 密码登录与登出

| 四步 | 说明 |
|------|------|
| **触发** | 用户输入邮箱+密码点击"登录"；或勾选"记住我" |
| **反馈** | loading → 登录成功跳转原页面；失败在表单顶部展示错误原因 |
| **规则** | 连续 5 次密码错误锁定 30 分钟；封禁用户（status=banned）拒绝登录并提示联系管理员；记住我 7 天免登录，否则 24 小时 |
| **循环** | 登录后可随时登出；登出后回到首页游客态 |

##### 3. 找回密码

| 四步 | 说明 |
|------|------|
| **触发** | 登录页点击"忘记密码"，输入注册邮箱 |
| **反馈** | 提示"验证码已发送至邮箱"，按钮进入 60s 倒计时 |
| **规则** | 验证码 5 分钟有效，单邮箱 10 分钟冷却；重置后旧密码立即失效，需重新登录 |
| **循环** | 重置成功跳转登录页；再次忘记可重新触发（受冷却限制） |

##### 异常分支

| 异常类型 | 触发条件 | 系统行为 | 用户提示 |
|---------|---------|---------|---------|
| 网络异常 | 注册/登录请求超时或断网 | 自动重试 1 次后失败 | Toast"网络异常，请重试" |
| 数据异常 | 邮箱已注册/格式错误/验证码错误 | 拦截提交 | 表单行内错误提示 |
| 权限异常 | 账号被封禁 | 拒绝登录 | 弹窗"账号已被封禁，请联系管理员" |
| 并发冲突 | 同一邮箱短时间内重复注册 | 幂等处理，返回已有账号 | 提示"该邮箱已注册，请直接登录" |
| 业务异常 | 密码错误 5 次触发锁定 | 锁定 30 分钟 | 提示"密码错误次数过多，请 30 分钟后重试" |

##### 业务规则
- 规则 1：密码一律 bcrypt 加密存储，任何场景不落明文
- 规则 2：验证码发送频率受限（单邮箱 10 分钟 1 次，全天 ≤ 5 次）
- 规则 3：注册默认角色 reader；作者角色由管理员授予（本期手动授予）

##### 全局状态

| 状态 | 呈现方式 |
|------|---------|
| 加载态 | 提交按钮 loading + 禁用防重复点击 |
| 空状态 | 注册/登录页无空状态；找回密码时未注册邮箱提示"邮箱未注册" |
| 错误态 | 表单行内红色错误文案 + 顶部 Toast |
| 成功态 | 注册成功自动登录跳首页；登录成功跳原页面 |
| 确认操作 | 找回密码重置需二次确认新密码 |
| 撤销操作 | 注册/登录不涉及撤销；验证码发送 60s 内不可重复触发 |

#### 4.3.2 文章创作与发布（内容域·文章创作 / 文章管理）

##### 1. 新建草稿

| 四步 | 说明 |
|------|------|
| **触发** | 作者在首页/个人中心点击"写文章"，进入创作中心 |
| **反馈** | 进入编辑器，自动生成"未命名-{日期}"标题占位，正文为空 |
| **规则** | 仅 author/admin 角色可进入；未登录跳转登录页 |
| **循环** | 可同时打开多个草稿；退出后草稿保留 |

##### 2. 富文本编辑与自动保存

| 四步 | 说明 |
|------|------|
| **触发** | 输入标题/正文/上传封面/选择分类与标签 |
| **反馈** | 内容实时渲染；停止输入 30s 自动保存，右上角显示"已保存 HH:mm:ss" |
| **规则** | 标题 1~100 字、正文 ≤ 100,000 字、标签 ≤ 5 个；图片上传支持 jpg/png/webp ≤ 5MB；草稿为 draft 状态仅作者可见 |

| **规则** | 标题与正文非空且通过敏感词校验；发布后状态变为 published；发布后 5 分钟内可撤回（回到草稿） |

|------|------|

| **反馈** | 编辑进入创作中心；下线后列表状态变为"已下线"；删除需二次确认弹窗 |
| **规则** | 仅作者本人可操作自己的文章；下线后文章不对读者展示；删除为逻辑删除，进入回收站 30 天可恢复 |
| **循环** | 已下线文章可"重新发布"回到 published |

##### 异常分支

| 异常类型 | 触发条件 | 系统行为 | 用户提示 |
|---------|---------|---------|---------|
| 网络异常 | 自动保存/发布请求失败 | 自动保存本地暂存，重试 3 次 | Toast"保存失败，正在重试"，保留本地编辑 |

##### 业务规则
- 规则 1：未保存离开编辑器时弹窗确认，防止丢稿
- 规则 2：封面图为空时列表页使用纯色占位，不阻塞发布
- 规则 3：文章下线/删除后，其评论对读者隐藏但保留数据

|------|---------|
| 加载态 | 编辑器骨架屏；发布/保存按钮 loading |

| 确认操作 | 发布、删除、下线均需二次确认 |
| 撤销操作 | 删除进回收站 30 天可恢复；发布 5 分钟内可撤回 |

| 权限异常 | 未登录评论 / 被封禁用户评论 | 拦截并跳转登录 | 提示"请先登录后再评论" |
| 并发冲突 | 文章被删除瞬间提交评论 | 拒绝写入 | 提示"文章已下线，无法评论" |
| 业务异常 | 1 分钟内重复评论 / 命中敏感词 | 拒绝或转待审核 | 提示"评论过于频繁"或"内容包含敏感词" |

##### 业务规则
- 规则 1：评论内容渲染前做 XSS 转义
- 规则 2：作者删除自己的文章后，评论不可再新增
- 规则 3：管理员可删除任意评论并记录操作日志

##### 全局状态

| 状态 | 呈现方式 |
|------|---------|
| 加载态 | 评论列表骨架屏；提交按钮 loading |
| 空状态 | 无评论时展示"还没有评论，来抢沙发" |
| 错误态 | 提交失败 Toast + 内容保留 |
| 成功态 | 提交成功 Toast；审核中展示状态文案 |
| 确认操作 | 删除自己的评论需二次确认 |
| 撤销操作 | 删除不可撤销（30 天内管理员可在后台恢复，P2） |

## 五、验收标准

### AC-01：注册 → 发布 → 阅读 完整链路（正常场景）
- **Given**：新用户无账号，网络正常，平台开放注册
- **When**：用户用未占用的邮箱注册成功并登录，开通作者角色后在创作中心发布一篇非空文章
- **Then**：文章状态变为已发布，出现在首页文章流中；未登录用户可打开详情页完整阅读；阅读数 +1

### AC-02：未登录发表评论被拦截（异常场景）
- **Given**：读者未登录，打开一篇已发布文章详情页
- **When**：在评论区输入内容并点击"发表评论"
- **Then**：系统拦截提交，跳转登录页；登录返回后原输入内容保留

### AC-03：密码连续错误触发锁定（异常场景）
- **Given**：已注册邮箱，账号状态 normal
- **When**：连续 5 次输入错误密码
- **Then**：第 5 次后账号登录锁定 30 分钟，提示"密码错误次数过多，请 30 分钟后重试"；期间即使输入正确密码也拒绝登录

### AC-04：评论超长被拒绝（边界场景）
- **Given**：已登录读者，打开文章详情页
- **When**：提交 501 字评论
- **Then**：提交被拦截，提示"评论不能超过 500 字"，输入内容保留可修改

### AC-05：空数据展示空状态（边界场景）
- **Given**：新平台无任何文章，或无评论的文章
- **When**：用户访问首页 / 文章详情页评论区
- **Then**：首页展示"暂无文章，去写第一篇"引导；评论区展示"还没有评论，来抢沙发"，均不报错

### AC-06：管理员审核评论闭环（正常场景）
- **Given**：平台开启评论审核，存在 1 条待审核评论
- **When**：管理员在后台审核通过该评论
- **Then**：评论状态变为已通过，读者在详情页可见；拒绝则仅提交者可见"未通过"

## 六、数据指标

### 6.1 核心成功指标（North Star）
- **指标名**：月活跃读者数（MAU-读者）
- **计算方式**：当月至少浏览 1 篇文章详情的去重读者数（登录+游客按设备 ID 去重）
- **目标值**：上线 12 周后达到 10,000
- **数据来源**：埋点系统（文章详情页浏览事件）

### 6.2 过程指标

| 指标名 | 计算方式 | 基准值 | 目标值 | 数据来源 |
|-------|---------|-------|-------|---------|
| 注册转化率 | 完成注册数 / 访问注册页数 | — | ≥ 30% | 埋点系统 |
| 周文章发布数 | 每周状态变为 published 的文章数 | 0 | ≥ 200 篇/周 | 文章库 |
| 平均阅读时长 | 详情页总时长 / 详情页浏览量 | — | ≥ 3 分钟 | 埋点系统 |
| 篇均评论数 | 已通过评论总数 / 已发布文章总数 | 0 | ≥ 3 条/篇 | 文章库+评论库 |
| 评论审核通过率 | 通过评论数 / 审核评论总数 | — | ≥ 90% | 审核后台 |
| 文章下线率 | 被强制下线文章数 / 发布文章总数 | 0 | < 2% | 管理后台 |

| 监控项 | 告警条件 | 告警级别 | 处理 SOP |
