## 一、概述与背景

##### 背景
- 当前缺乏统一的内容发布与互动平台：文章散落各处、无法沉淀，账号体系缺失导致无法管理个人内容。
- 需要一个支持**注册登录、文章发布、评论互动**的完整博客系统，让创作者发布内容、读者互动、管理员治理内容。

##### 目标
- 目标 1：建立账号体系，访客→注册转化率 ≥ 60%。
- 目标 2：支持文章发布与全生命周期管理，发文成功率 100%（除敏感词拦截外），单篇发布耗时 < 3 分钟。
- 目标 3：支持评论互动，评论渗透率（有评论文章占比）≥ 40%，评论回复率 ≥ 30%。
- 目标 4：内容安全可控，违规内容（文章/评论）处理时长 < 24 小时，处置全程留痕。

##### 角色清单

| 角色 | 职责 | 核心诉求 |
|------|------|---------|
| 游客 | 未登录浏览文章与评论，可注册 | 无需注册即可阅读 |
| 注册用户（博主） | 注册登录、发布/编辑/删除自己的文章、发表评论 | 快速发布并管理自己的内容 |
| 管理员 | 用户管理、内容审核与下架/删除、处置留痕 | 高效治理全部内容 |

##### 场景清单

### 场景 1：游客浏览文章（核心）
- **发生时态**：日常
- **角色**：游客
- **目标**：浏览文章列表与详情、阅读评论
- **前置条件**：无，系统开放访问

### 场景 2：用户注册（核心）
- **发生时态**：首次
- **角色**：游客
- **目标**：创建账号（用户名/邮箱/密码），获得发文与评论资格
- **前置条件**：未登录，进入注册页

### 场景 3：用户登录（核心）
- **发生时态**：日常
- **角色**：注册用户
- **目标**：登录进入个人中心，获得发文/评论/管理权限
- **前置条件**：已有账号，账号状态为 active

### 场景 4：博主发布文章（核心）
- **发生时态**：日常
- **角色**：注册用户
- **目标**：撰写并发布文章（标题/正文/分类/标签），可保存草稿
- **前置条件**：已登录

### 场景 5：用户发表评论（核心）
- **发生时态**：日常
- **角色**：注册用户
- **目标**：对文章发表一级评论或回复他人评论
- **前置条件**：已登录，文章处于已发布状态

### 场景 6：管理员内容治理（边缘）
- **发生时态**：日常/峰值
- **角色**：管理员
- **目标**：审核待审内容、下架/删除违规文章与评论、禁用违规用户
- **前置条件**：管理员权限

### 场景 7：异常场景（边缘）
- **发生时态**：异常
- **角色**：游客/注册用户/管理员
- **目标**：断网、数据为空、无权限、并发冲突时获得可理解的降级体验
- **前置条件**：网络异常 / 数据缺失 / 权限不足 / 多人并发操作

##### 场景-角色矩阵

| 场景 | 角色 | 核心/边缘 | 发生时态 |
|------|------|----------|---------|
| 游客浏览文章 | 游客 | 核心 | 日常 |
| 用户注册 | 游客 | 核心 | 首次 |
| 用户登录 | 注册用户 | 核心 | 日常 |
| 博主发布文章 | 注册用户 | 核心 | 日常 |
| 用户发表评论 | 注册用户 | 核心 | 日常 |
| 管理员内容治理 | 管理员 | 边缘 | 日常 |
| 异常场景 | 全员 | 边缘 | 异常 |

### 3.2 业务链路

#### 核心链路 1：文章发布链路（博主视角）

```text
┌──────────┐  填写并提交   ┌──────────┐  校验登录态/必填  ┌──────────┐
│ 写文章页  │ ───────────► │ 文章发布  │ ──────────────► │ 敏感词检测 │
└──────────┘              └────┬─────┘                └────┬─────┘
                               │ <异常>                    │ 未命中
                               ▼                           ▼
                         ┌──────────┐                 ┌──────────┐
                         │ 拦截并提示 │                 │ 文章上架  │
                         └──────────┘                 └────┬─────┘
                                                          │ 命中
                                                          ▼
                                                    ┌──────────┐
                                                    │ 待审核   │
                                                    └──────────┘
```

**链路说明**：博主在写文章页提交内容 → 文章发布模块校验登录态与必填项 → 敏感词检测：未命中直接上架（状态：已发布），命中进入待审核（状态：待审核）；校验失败拦截并提示具体原因。

#### 核心链路 2：评论互动链路（读者视角）

```text
┌──────────┐  提交评论    ┌──────────┐  校验登录态/内容  ┌──────────┐
│ 评论区    │ ──────────► │ 评论发布  │ ──────────────► │ 敏感词检测 │
└──────────┘             └────┬─────┘                 └────┬─────┘
                              │ <异常：未登录>             │ 未命中
                              ▼                           ▼
                        ┌──────────┐                 ┌──────────┐
                        │ 跳转登录  │                 │ 评论上架  │
                        └──────────┘                 └────┬─────┘
                                                         │ 命中
                                                         ▼
                                                   ┌──────────┐
                                                   │ 待审核   │
                                                   └──────────┘
```

**链路说明**：读者在文章详情页评论区提交 → 校验登录态（未登录跳转登录页并回跳）与内容合法性 → 敏感词检测：未命中即时上架展示，命中进入待审核队列；空评论/超长评论拦截提示。

### 3.3 状态流转

#### 文章（Article）状态机

```text
      ┌──────────┐  点击发布·未命中敏感词   ┌──────────┐
 ────►│   草稿    │ ─────────────────────► │  已发布   │
      └────┬─────┘                        └────┬─────┘
           │ 点击发布·命中敏感词                │ 管理员下架
           ▼                                   ▼
      ┌──────────┐  审核通过              ┌──────────┐
      │  待审核   │ ─────────────────────►│  已下架   │
      └────┬─────┘                       └────┬─────┘
           │ 审核驳回                          │ 重新上架
           ▼                                   ▼
      ┌──────────┐                      ┌──────────┐
      │  已驳回   │                      │  已发布   │
      └──────────┘                      └──────────┘

      （任意非删除状态）── 作者/管理员删除(软删除) ──► 已删除
      （已删除）──────── 回收站恢复(30天内) ────────► 草稿/已发布
```

##### 状态定义

| 状态 | 含义 | 允许的下一状态 | 触发迁移的动作/条件 |
|------|------|---------------|-------------------|
| 草稿 | 作者保存但未发布，仅作者可见 | 已发布、待审核、已删除 | 作者点击发布（未命中/命中敏感词）；作者删除 |
| 待审核 | 命中敏感词待管理员审核 | 已发布、已驳回、已删除 | 管理员审核通过/驳回；管理员删除 |
| 已驳回 | 审核不通过，退回作者 | 草稿、已删除 | 作者修改后重新保存；作者删除 |
| 已发布 | 公开可见，可被浏览评论 | 已下架、已删除 | 管理员下架；作者/管理员删除 |
| 已下架 | 详情页不可访问，仅后台可见 | 已发布、已删除 | 管理员重新上架；作者/管理员删除 |
| 已删除 | 软删除，进回收站 | 草稿、已发布、已删除（物理删除） | 回收站恢复；30 天到期物理删除 |

##### 非法迁移

| 从 | 到 | 拒绝原因 | 系统行为 |
|----|-----|---------|---------|
| 已发布 | 草稿 | 已发布文章不允许退回草稿态 | 拒绝并提示「请先下架再编辑」 |
| 待审核 | 草稿 | 审核中不允许作者直接修改 | 拒绝并提示「审核中不可编辑」 |
| 已驳回 | 已发布 | 驳回后必须重新发布走检测流程 | 拒绝并提示「请修改后重新发布」 |

#### 评论（Comment）状态机

```text
      ┌──────────┐  提交评论·未命中敏感词  ┌──────────┐
 ────►│  待发布   │ ─────────────────────► │  已发布   │
      └────┬─────┘                       └────┬─────┘
           │ 命中敏感词                       │ 作者/管理员删除
           ▼                                 ▼
      ┌──────────┐  审核通过            ┌──────────┐
      │  待审核   │ ──────────────────► │  已删除   │
      └──────────┘                     └──────────┘
```

##### 状态定义

| 状态 | 含义 | 允许的下一状态 | 触发迁移的动作/条件 |
|------|------|---------------|-------------------|
| 待发布 | 提交成功、展示前状态（瞬时态） | 已发布、待审核 | 未命中敏感词即时上架；命中敏感词转待审核 |
| 待审核 | 命中敏感词待管理员审核 | 已发布、已删除 | 管理员审核通过/删除 |
| 已发布 | 公开可见 | 已删除 | 文章作者（本文章下）/管理员删除 |
| 已删除 | 不可见，展示「评论已删除」占位 | — | 终态 |

##### 非法迁移

| 从 | 到 | 拒绝原因 | 系统行为 |
|----|-----|---------|---------|
| 已删除 | 已发布 | 删除为终态，不支持恢复 | 拒绝并提示「已删除评论不可恢复」 |
| 已发布 | 待审核 | 已上架评论不再重复审核 | 拒绝 |

### 3.4 数据字典

## 四、需求详细描述

### 4.1 背景与目标

博客系统面向「创作—阅读—互动—治理」闭环：创作者发布文章，读者浏览互动，管理员保障内容安全。本期聚焦注册登录、文章发布与评论三大核心能力，保证闭环可用、体验顺畅、内容可控。

##### 本期范围
- ✅ 包含：用户注册、登录/退出、文章发布（含草稿）、文章管理（编辑/下架/删除/回收站）、文章浏览（列表/详情/分类标签筛选）、评论发表与回复、评论/文章审核、用户管理（禁用）、审核留痕。
- ❌ 不包含：找回密码、邮箱验证强制、第三方登录、点赞/收藏/关注、站内私信、图片/附件上传、移动端 App、多语言。

### 4.2 用户故事

#### Story 1：游客浏览文章
- **作为** 游客
- **我希望** 无需注册即可浏览文章列表与详情、阅读评论
- **以便** 快速获取内容，降低阅读门槛
- **没有这个功能，用户会怎样？** 阅读需注册，大量潜在读者流失
- **优先级**：P0

#### Story 2：用户注册
- **作为** 游客
- **我希望** 用用户名/邮箱/密码注册账号并自动登录
- **以便** 获得发文与评论资格
- **没有这个功能，用户会怎样？** 无法沉淀身份，无法创作互动
- **优先级**：P0

#### Story 3：用户登录
- **作为** 注册用户
- **我希望** 用账号密码登录并保持登录态
- **以便** 进入个人中心发文和评论
- **没有这个功能，用户会怎样？** 无法使用任何需身份的能力
- **优先级**：P0

#### Story 4：发布文章
- **作为** 注册用户
- **我希望** 填写标题/正文/分类/标签后一键发布，且编辑时自动保存草稿
- **以便** 快速分享内容且不因意外丢失
- **没有这个功能，用户会怎样？** 核心创作场景不可用
- **优先级**：P0

#### Story 5：管理自己的文章
- **作为** 注册用户
- **我希望** 编辑、下架、删除自己的文章，删除后可进回收站恢复
- **以便** 持续维护内容质量
- **没有这个功能，用户会怎样？** 错误内容无法撤回，体验受损
- **优先级**：P1

#### Story 6：发表评论
- **作为** 注册用户
- **我希望** 对文章发表评论或回复他人
- **以便** 与作者和其他读者互动
- **没有这个功能，用户会怎样？** 平台无互动，读者留存低
- **优先级**：P1

#### Story 7：管理员内容治理
- **作为** 管理员
- **我希望** 审核待审内容、下架/删除违规文章与评论、禁用违规用户并记录原因
- **以便** 保障平台内容安全合规
- **没有这个功能，用户会怎样？** 违规内容泛滥，平台不可控
- **优先级**：P1

#### Story 8：账号安全
- **作为** 注册用户
- **我希望** 修改密码、查看个人信息
- **以便** 保障账号安全
- **没有这个功能，用户会怎样？** 密码泄露后无法自救
- **优先级**：P2

#### 4.3.1 用户注册

##### 1. 填写注册信息

| **规则** | 用户名 3-20 字符且唯一；邮箱格式合法且唯一；密码 ≥8 位含字母和数字；两次密码一致；防重复提交 |

|------|------|
| **触发** | 注册请求返回结果 |
| **反馈** | 成功 Toast「注册成功，已自动登录」并跳转；失败展示具体原因 |

##### 业务规则
- 规则 1：用户名、邮箱全局唯一（唯一索引兜底并发）。
- 规则 2：密码仅存哈希（如 bcrypt），任何场景不回显。
- 规则 3：同 IP 注册 ≤10 次/小时，超出限流。

##### 业务规则
- 规则 1：软删除（status=deleted）进回收站，30 天后物理删除。
- 规则 2：已发布文章不可直接编辑正文，需先下架（或允许编辑草稿式再发布[待确认]）。
- 规则 3：回收站恢复后回到原状态（草稿/已发布）。

##### 全局状态

| 状态 | 呈现方式 |
|------|---------|
| 加载态 | 列表骨架屏 |
| 空状态 | 「还没有文章，去写第一篇」+ 引导按钮 |
| 错误态 | 操作失败 Toast |
| 成功态 | Toast「已下架/已删除/已恢复」 |
| 确认操作 | 下架、删除、永久删除均二次确认 |
| 撤销操作 | 删除可撤销（回收站 30 天内恢复）；永久删除不可撤销 |

#### 4.3.5 评论互动

##### 1. 发表评论/回复

| 四步 | 说明 |
|------|------|
| **触发** | 已登录用户在评论区输入内容，点击「发表」/「回复」 |
| **反馈** | 未命中敏感词即时展示并评论数 +1；命中敏感词提示「评论已提交，审核通过后展示」 |
| **规则** | 仅登录用户可评论；内容 1-500 字符；回复设置 parent_id；文章关闭评论时禁止（本期默认开启） |

##### 2. 查看评论

| 四步 | 说明 |
|------|------|
| **触发** | 打开文章详情页 |
| **反馈** | 评论按时间倒序展示，回复缩进展示；显示评论总数 |
| **规则** | 已删除评论展示「评论已删除」占位；文章下架/删除时评论不对外展示 |
| **循环** | 评论多时翻页/加载更多 |

##### 异常分支

| 异常类型 | 触发条件 | 系统行为 | 用户提示 |
|---------|---------|---------|---------|
| 网络异常 | 提交超时 | 重试 1 次后放弃 | Toast「评论失败，请重试」 |
| 数据异常 | 内容为空/超 500 字符 | 拦截 | 「评论内容 1-500 字」 |
| 权限异常 | 未登录点击评论 | 跳转登录，回跳原文 | 登录后自动定位评论区 |
| 并发冲突 | 同一文章高并发评论 | 计数原子更新 | 无提示 |
| 业务异常 | 命中敏感词/文章已删除 | 转待审核 / 拒绝 | 「评论已提交，审核通过后展示」/「文章不存在」 |

##### 业务规则
- 规则 1：文章作者可删除自己文章下的任意评论；管理员可删除任意评论。
- 规则 2：删除为软删除，展示「评论已删除」占位。
- 规则 3：评论计数与 article.comment_count 原子同步。

##### 1. 审核队列

| 四步 | 说明 |

| **触发** | 进入管理后台·待审核列表（文章/评论/举报） |
| **反馈** | 分页展示待审核内容，可展开查看原文 |
| **规则** | 仅管理员可见；按提交时间正序（先到先审） |

|------|------|
| **触发** | 对目标执行通过 / 驳回 / 删除 |

| **规则** | 处置须填写原因（1-200 字）；处置写入 audit_log 留痕 |
| **循环** | 处置后不可直接撤销，如误判走人工申诉流程[待确认] |

##### 业务规则
- 规则 1：所有处置动作强制留痕（audit_log）。
- 规则 2：驳回文章回草稿态并通知作者；删除不可恢复。

## 五、验收标准

### AC-01：注册成功（正常场景）
- **Given**：游客在注册页填写合法的用户名、邮箱、密码（≥8 位含字母数字）
- **When**：点击「注册」
- **Then**：创建账号并自动登录，跳转首页，Toast「注册成功，已自动登录」

### AC-02：注册冲突（异常场景）
- **Given**：用户名或邮箱已被其他账号占用
- **When**：提交注册
- **Then**：不创建账号，对应字段高亮提示「用户名已存在」/「邮箱已被注册」

### AC-03：登录锁定（异常场景）
- **Given**：同一账号 30 分钟内密码连续错误 5 次
- **When**：第 6 次尝试登录
- **Then**：拒绝登录并提示「尝试次数过多，账号已锁定 30 分钟」，期间任何正确密码也无效

### AC-04：发布文章（正常场景）
- **Given**：已登录用户填写合法标题与正文（未命中敏感词）
- **When**：点击「发布」
- **Then**：文章状态变为已发布，跳转详情页，首页可见，published_at 正确记录

### AC-05：敏感词拦截（异常场景）
- **Given**：正文命中敏感词库
- **When**：点击「发布」
- **Then**：文章进入待审核，提示「文章已提交，审核通过后展示」，首页不可见

### AC-06：发布边界（边界场景）
- **Given**：标题为空或超过 100 字符，或正文为空
- **When**：点击「发布」
- **Then**：拦截发布，字段级提示具体错误，不产生新文章

### AC-07：发表评论（正常场景）
- **Given**：已登录用户在已发布文章的详情页
- **When**：提交 1-500 字的合法评论
- **Then**：评论即时展示，评论数 +1，作者可看到

### AC-08：未登录评论（异常场景）
- **Given**：游客点击评论输入框或发表按钮
- **When**：提交评论
- **Then**：跳转登录页，登录成功后回跳原文章并定位评论区

### AC-09：越权操作（权限异常）
- **Given**：用户 A 登录后尝试编辑/删除用户 B 的文章
- **When**：提交操作
- **Then**：拒绝操作并提示「无权操作该文章」，数据不变

### AC-10：审核处置（正常场景）
- **Given**：管理员在待审核队列中打开一条待审核评论
- **When**：点击「通过」并确认
- **Then**：评论上架展示，写入 audit_log（含操作人与时间）

### AC-11：并发审核（并发异常）
- **Given**：两名管理员同时打开同一条待审核内容
- **When**：其中一人先完成处置
- **Then**：后处置者收到「该内容已被其他管理员处理」，队列自动刷新

## 六、数据指标

### 6.1 核心成功指标（North Star）
- **指标名**：周活跃发文用户数（WAU-Author）
- **计算方式**：近 7 天至少成功发布 1 篇文章的去重用户数
- **目标值**：上线 4 周后 ≥ 500
- **数据来源**：文章表（published_at 在近 7 天）按 author_id 去重聚合

### 6.2 过程指标

| 指标名 | 计算方式 | 基准值 | 目标值 | 数据来源 |
|-------|---------|-------|-------|---------|
| 注册转化率 | 注册成功数 / 访客数 | — | ≥ 60% | 埋点 + 用户表 |
| 发文成功率 | 发布成功数 / 发布尝试数 | — | 100%（敏感词拦截除外） | 埋点 |
| 文章平均发布耗时 | 进入编辑页 → 发布成功耗时均值 | — | < 3 分钟 | 埋点 |
| 评论渗透率 | 有评论文章数 / 已发布文章数 | — | ≥ 40% | 文章/评论表 |
| 评论回复率 | 被回复评论数 / 评论总数 | — | ≥ 30% | 评论表 |
| 待审核处理时长 | 审核完成时间 − 提交时间 | — | < 24h | 审核记录 |
| 7 日留存率 | 注册后第 7 天仍登录用户 / 当日注册用户 | — | ≥ 20% | 埋点 |

### 6.3 异常告警阈值

| 监控项 | 告警条件 | 告警级别 | 处理 SOP |
|-------|---------|---------|---------|
| 注册/登录接口成功率 | 成功率 < 99% 持续 5 分钟 | P0 | 排查服务与数据库，必要时回滚 |

| 评论接口 P95 延迟 | > 800ms 持续 5 分钟 | P2 | 扩容 / 排查慢查询 |
| 存储使用率 | > 80% | P2 | 清理回收站 / 扩容 |
