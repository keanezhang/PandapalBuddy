- 文档版本：v1.0
- 编写日期：2026-08-11
- 编写人：PandaPal 样本执行 Agent

## 1. 产品概述

### 1.1 产品背景
在线教育需求持续增长，需要一个统一的在线课程平台，将课程内容、作业练习、成绩管理三个核心教学环节线上化，覆盖学生、讲师、管理员三类角色的协作闭环。

### 1.2 产品目标
- 让学生可以随时随地看课、做作业、提交作业并查看成绩。
- 让讲师可以便捷地上传课程、布置作业、批改作业。
- 让管理员可以审核课程内容，确保上架课程合规、优质。
- 打通"课程上架 → 学习 → 作业 → 成绩"的完整业务闭环。

### 1.3 产品范围
- 本期范围：课程管理（上传/审核/上架/浏览）、作业管理（布置/提交/批改）、成绩管理（发布/查看）、角色与权限基础能力。
- 不在本期范围：直播授课、论坛社区、支付与订单、多租户/机构管理。

### 1.4 名词解释
- 课程：讲师上传、管理员审核通过后上架的学习内容，可包含多个章节/课时。
- 作业：讲师在课程下布置的任务，学生需在截止时间前提交。
- 成绩：讲师对作业批改后给出的评分，学生可查看。
- 审核：管理员对讲师上传课程的合规性检查，决定上架或驳回。

## 2. 用户角色与权限

### 2.1 学生（Student）
- 角色说明：平台的主要学习用户。
- 核心权限：浏览/检索课程、查看课程详情、查看作业、提交作业、查看成绩。
- 无权限：上传课程、审核课程、批改作业。

### 2.2 讲师（Instructor）
- 角色说明：教学内容的生产者。
- 核心权限：上传/编辑自己名下的课程、在自己课程下布置作业、批改学生提交的作业并打分。
- 无权限：审核课程上架（只能提交审核）、浏览其他讲师课程的管理操作、以学生身份提交作业。

### 2.3 管理员（Admin）
- 角色说明：平台运营与合规管理者。
- 核心权限：审核课程上架（通过/驳回）、下架违规课程、管理用户账号。
- 无权限：参与教学业务（布置/批改作业、提交作业）。

## 3. 功能需求

### 3.1 学生端功能

#### 3.1.1 浏览与查看课程
- 课程列表页：支持按分类筛选、关键词搜索、按热度/更新时间排序。
- 课程详情页：展示课程简介、章节/课时结构、讲师信息、已选课人数。
- 学习记录：记录学生已学课时，支持断点续看（若含视频）。
- 收藏/选课：学生可收藏或加入"我的课程"。

#### 3.1.2 查看作业
- 在课程详情页或"作业"入口查看讲师布置的作业列表。
- 作业详情展示：作业标题、要求说明、截止时间、分值、附件（可选）。
- 明确展示作业状态：未开始 / 待提交 / 已提交 / 已批改。

#### 3.1.3 提交作业
- 提交方式：文本作答 + 附件上传（支持常见文档/图片格式，附件大小限制见非功能需求）。
- 截止时间前可修改并重新提交，系统保留最近一次提交。
- 截止时间后按平台规则锁定提交（是否允许补交由讲师配置）。
- 提交成功后系统回执确认，学生可在作业列表看到"已提交"状态。

#### 3.1.4 查看成绩
- 成绩列表：按课程维度展示各次作业得分、总分、批改评语。
- 成绩明细：展示讲师批改的打分依据与文字评语。
- 成绩通知：批改完成后学生可收到站内/通知提醒（见非功能需求）。

### 3.2 讲师端功能

#### 3.2.1 上传课程
- 创建课程：填写课程名称、分类、简介、封面、适用人群、学习目标。
- 上传章节/课时：支持文本、视频、附件等多种内容形式。
- 草稿与提交：课程可先存草稿，完善后提交审核。
- 课程状态流转：草稿 → 待审核 → 已上架 / 已驳回（可修改后重新提交）→ 已下架。
- 已上架课程支持讲师发起更新，更新内容需再次过审或按平台策略生效。

#### 3.2.2 布置作业
- 在名下课程内创建作业：标题、题目/要求、截止时间、满分分值、是否允许补交。
- 支持为作业关联课时或章节。
- 作业创建后立即对学生可见（或按设定的发布时间可见）。

#### 3.2.3 批改作业
- 作业提交列表：按课程/作业维度查看所有学生的提交情况（未提交/已提交）。
- 批改操作：逐份查看学生提交内容，输入得分（不超过满分）与文字评语。
- 批量能力：支持按提交时间排序、标记已批/未批，支持一键"全部标记为已读"等轻量批量操作。
- 批改完成后成绩自动对学生可见，触发成绩通知。

### 3.3 管理员端功能

#### 3.3.1 审核课程上架
- 待审核列表：展示所有讲师提交审核的课程，含提交时间、讲师、分类。
- 审核操作：查看课程完整内容后进行"通过"或"驳回"。
- 驳回必填原因：驳回时必须填写原因，原因回传给讲师供其修改。
- 审核记录：保留审核人、审核时间、审核结论的日志，便于追溯。

#### 3.3.2 课程管理（补充）
- 对已上架课程可执行下架操作（如内容违规），下架后学生不可再访问。
- 用户管理：禁用/启用学生或讲师账号。

### 3.4 公共能力
- 登录与鉴权：统一账号体系，按角色分配权限（RBAC）。
- 消息通知：作业布置、提交成功、批改完成、审核结果等关键节点发送站内通知。
- 基础搜索与分页：课程列表、作业列表、待审核列表均支持分页与状态筛选。

## 4. 核心业务流程

### 4.1 课程上架流程（讲师 + 管理员）
1. 讲师创建课程并填写完整信息，上传章节内容。
2. 讲师提交审核，课程状态变为"待审核"。
3. 管理员在待审核列表查看课程内容。
4. 审核通过 → 课程上架，学生可见；审核驳回 → 课程退回，讲师收到驳回原因并修改后重新提交。
5. 已上架课程可被管理员下架（内容违规或运营需要）。

### 4.2 作业闭环流程（讲师 + 学生）
1. 讲师在课程下布置作业（含要求、截止时间、分值）。
2. 学生查看作业并在截止时间前提交（文本 + 附件）。
3. 学生可修改重交直至截止；系统锁定截止后的提交（是否允许补交由讲师配置）。
4. 讲师查看提交列表，逐份批改并给出得分与评语。
5. 批改完成 → 成绩对学生可见，学生收到通知并可查看成绩明细。

### 4.3 状态机摘要
- 课程：草稿 → 待审核 → 已上架 →（可）已下架；待审核可被驳回回草稿/待修改。
- 作业：进行中（可提交）→ 已截止（锁定提交）→ 已批改（成绩发布）。
- 提交：待提交 → 已提交（可重交）→ 已批改。

## 5. 非功能需求

### 5.1 性能
- 课程列表/详情页 P95 响应时间不超过 2 秒。
- 支持并发在线看课用户不低于 1,000 人（首期）。
- 作业提交接口 P95 响应时间不超过 3 秒。

### 5.2 安全与合规
- 密码加密存储；敏感操作（审核、下架、删除）需鉴权与操作日志。
- 附件上传需校验文件类型与大小，防止恶意文件（见 5.3 限额）。
- 课程内容需符合平台内容合规要求，管理员审核兜底。

### 5.3 容量与限额
- 单作业附件上限：50 MB；单课程视频总时长与存储上限按平台套餐策略配置。
- 支持的文件类型：常见文档（doc/docx/pdf/txt）、图片（jpg/png）、视频（mp4/webm）。

### 5.4 可用性与兼容性
- 首期支持主流浏览器（Chrome/Edge/Safari 最新两个大版本）与移动端 H5。
- 服务可用性目标不低于 99.5%（月度）。

### 5.5 可扩展性
- 角色与权限采用 RBAC 模型，便于后续新增角色（如助教）。
- 课程内容形式可扩展（后续支持直播、测验等）。

## 6. 页面清单（信息架构）

### 6.1 学生端
- 首页 / 课程列表页
- 课程详情页（含章节学习）

- 作业列表页 / 作业详情页（含提交表单）

- 审核工作台（待审核列表）

## 7. 里程碑规划

- 里程碑 M1（第 1-2 周）：账号与角色权限、课程上传与审核上架闭环。
- 里程碑 M2（第 3-4 周）：作业布置、学生提交、讲师批改与成绩闭环。
- 里程碑 M3（第 5 周）：通知、搜索、性能优化与联调验收。
- 里程碑 M4（第 6 周）：全量回归、上线发布。

## 8. 附录：关键数据字段定义

### 8.1 课程（Course）
- 课程ID、课程名称、分类、简介、封面图、讲师ID、状态（草稿/待审核/已上架/已驳回/已下架）、审核人ID、审核时间、驳回原因、创建时间、更新时间。

### 8.2 课时（Lesson）
- 课时ID、课程ID、章节序号、标题、内容类型（文本/视频/附件）、内容地址、时长、排序。

### 8.3 作业（Assignment）
- 作业ID、课程ID、标题、要求说明、满分分值、截止时间、是否允许补交、发布时间、创建时间。

### 8.4 作业提交（Submission）
- 提交ID、作业ID、学生ID、作答文本、附件地址、提交时间、状态（已提交/已批改）、最后修改时间。

### 8.5 成绩（Grade）
- 成绩ID、提交ID、作业ID、学生ID、得分、评语、批改人ID（讲师）、批改时间。

### 8.6 用户（User）
- 用户ID、姓名、手机号/邮箱、角色（学生/讲师/管理员）、状态（启用/禁用）、创建时间。

## 9. 待确认问题（开放项）
- 视频内容是否支持试看与防盗链策略。
- 作业截止后补交是否需要讲师逐单审批。
- 课程内容更新后是否需要重新走完整审核流程。
- 首期是否接入第三方登录（微信/钉钉）。
