# PRD · 在线课程平台

> 版本：v1.0 | 日期：2025-07-20（假设值，落地前请更新）| 复杂度：复杂

## 一、概述与背景

##### 背景
当前课程内容分散在网盘、聊天群与线下课堂，学习、作业提交、批改与成绩公布割裂在多个工具中，学生与讲师需在多个系统间反复切换，效率低且数据易丢失。课程上架缺少统一审核入口，内容质量与合规性无法保障。

##### 目标
- 目标 1：课程上架审核流程线上化，管理员初审时效 ≤ 24 小时
- 目标 2：作业提交全流程线上化，按时提交率 ≥ 95%
- 目标 3：批改闭环线上化，批改平均耗时 ≤ 48 小时
- 目标 4：成绩数据统一沉淀，学生可随时查询成绩与批改反馈

##### 角色清单

| 角色 | 职责 | 核心诉求 |
|------|------|---------|
| 学生 | 浏览学习课程、完成并提交作业、查看成绩 | 作业不丢失、成绩透明可查 |
| 讲师 | 上传课程内容、布置作业、批改作业并评分 | 批改高效、教学数据不丢 |
| 管理员 | 审核课程上架、治理违规内容 | 审核流程清晰、内容可控 |

##### 场景清单

### 场景 1：学生浏览并学习课程（核心）
- **发生时态**：日常
- **角色**：学生
- **目标**：找到目标课程并完成章节学习
- **前置条件**：学生已登录并加入课程

### 场景 2：学生完成并提交作业（核心）
- **发生时态**：日常
- **角色**：学生
- **目标**：在截止时间前完成作业并成功提交
- **前置条件**：讲师已布置作业且未到截止时间

### 场景 3：学生查看成绩与批改反馈（核心）
- **发生时态**：日常
- **角色**：学生
- **目标**：查看作业得分、评语与课程总成绩
- **前置条件**：讲师已完成批改

### 场景 4：讲师上传课程内容（核心）
- **发生时态**：日常
- **角色**：讲师
- **目标**：创建课程并上传章节视频/资料，提交审核
- **前置条件**：讲师已通过身份认证

### 场景 5：讲师布置作业（核心）
- **发生时态**：日常
- **角色**：讲师
- **目标**：为课程创建作业、设置截止时间并发布
- **前置条件**：课程已上架

### 场景 6：讲师批改作业（核心）
- **发生时态**：日常
- **角色**：讲师
- **目标**：查看学生提交、评分并写评语
- **前置条件**：学生已提交作业

### 场景 7：管理员审核课程上架（核心）
- **发生时态**：日常
- **角色**：管理员
- **目标**：审核讲师提交的课程，通过后上架或驳回
- **前置条件**：讲师已提交课程审核

### 场景 8：作业提交失败（网络/超时）重试（边缘）
- **发生时态**：异常
- **角色**：学生
- **目标**：网络异常情况下作业提交不丢失
- **前置条件**：学生已填写作业但网络中断

### 场景 9：选课高峰期大量学生同时提交（边缘）
- **发生时态**：峰值
- **角色**：学生 / 讲师
- **目标**：高并发提交不丢数据、成绩不错乱
- **前置条件**：选课季，千人级学生同时提交作业
