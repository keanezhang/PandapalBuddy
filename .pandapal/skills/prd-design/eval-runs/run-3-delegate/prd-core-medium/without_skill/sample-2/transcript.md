## 3. 关键决策与假设

需求方明确"信息不足的部分你来判断"，且本环境为无人值守、无提问渠道，故全部采用合理默认假设，并统一标注为"假设/默认值"且设计为管理员可配置项：

1. **积分获得规则**：实付金额 1 元 = 1 积分（向下取整，不含运费/券抵扣/退款）；按会员等级倍率加成（普 1.0 / 银 1.2 / 金 1.5 / 钻 2.0，取支付时等级快照）；单笔上限 10,000、单日上限 50,000 防刷分；确认收货后实时发放，退款等额扣回。
2. **积分有效期**：默认 12 个自然月、按自然月批量过期（FIFO 先到期先过期，兑换优先消耗最早到期积分）。
3. **兑换限制**：优惠券即时发券；商品类兑换冻结等额积分，发货/确认收货后转扣减，取消则解冻；设限兑次数与频控（默认每品每日 1 次、每月 3 次，每分钟 10 次请求上限）。
4. **角色与权限**：普通用户 / 运营 / 客服 / 超管，RBAC 权限点模型，人工调分需审批留痕。
5. **范围决策**：签到/任务积分、积分+现金混合支付、积分转赠均划入一期之外（V1.1/V2.0），避免范围蔓延。
6. **合规**：积分不可提现/转让，注销清零并告知，含积分说明页。
7. 隔离约束：未加载、未引用名为 prd-design 的 skill，未读取其目录内容；PRD 完全基于通用产品方法论撰写。
