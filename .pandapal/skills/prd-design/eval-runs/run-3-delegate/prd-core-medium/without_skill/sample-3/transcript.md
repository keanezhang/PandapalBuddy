## 3. 关键决策与假设

### 3.1 信息不足处的判定（详见 PRD §18 假设清单 A1–A10）

1. **场景与币种**：按电商场景（人民币）设计，积分比例默认 1 元实付 = 1 积分，可后台配置。
2. **发放时点**：积分在订单**签收完成**后发放（非支付即发），退款按金额比例扣回——降低刷单/退款套利风险。
3. **有效期**：默认 12 个月滚动有效（可配置），过期自动清零并通知。
4. **价值锚定**：100 积分 ≈ 1 元权益价值，作为运营定价参考。
5. **兑换规则**：积分不足/库存不足禁止兑换；虚拟权益（含优惠券）即时发放且不可退；实物按状态机支持取消/售后。
6. **并发一致性**：余额扣减、流水写入、兑换订单创建、库存扣减同事务（行锁 + 乐观锁 + 幂等键），避免负余额与超卖。
7. **退款竞态**：扣回时余额不足则产生"欠积分"，后续获得积分优先补足、补足前禁兑。
8. **范围裁剪**：会员等级/成长值、签到活动、积分抵现、个性化推荐均列为二期（需求未提及）。
9. **库存策略**：积分商城实物商品采用独立库存，不与主商城库存联动（降低改造复杂度，列为开放问题）。
