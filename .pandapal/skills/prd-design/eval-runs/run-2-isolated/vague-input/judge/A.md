## 1. 背景与问题

### 1.1 背景
个人用户与小型团队在日常工作中普遍依赖多套工具（聊天软件、电子表格、邮件）来跟踪任务，导致信息分散、进度难以同步、责任归属不清晰。

### 1.2 问题陈述
- 任务分散在多个渠道，缺少统一视图，容易遗漏。
- 任务优先级不明确，团队无法快速对齐"先做什么"。
- 缺乏简单的进度跟踪与提醒机制，交付延期频发。

### 1.3 机会
提供一个轻量、低学习成本的任务管理 Web 应用，让个人与小型团队在 5 分钟内上手，集中管理任务、跟踪进度并获得必要提醒。

---

## 2. 目标与非目标

### 2.1 产品目标
- **G1**：让用户在一个界面内创建、分配、跟踪全部任务，任务完成率提升。
- **G2**：支持按项目/标签/负责人多维度筛选，5 秒内定位任意任务。
- **G3**：提供基础提醒与看板视图，降低任务遗漏率。
- **G4**：单人使用 0 配置，团队使用 10 分钟内完成初始化。

### 2.2 成功指标（示例）
| 指标 | 目标值 |
| --- | --- |
| 周活跃用户（WAU） | 上线 3 个月后 ≥ 1,000 |
| 任务按时完成率 | ≥ 80% |
| 新用户激活率（创建首个任务） | ≥ 70% |
| 7 日留存率 | ≥ 35% |

### 2.3 非目标（本期不做）
- 不做即时通讯/群聊功能。
- 不做复杂项目排期（甘特图、资源负载）。
- 不做移动原生 App（仅响应式 Web，后续迭代）。
- 不做第三方应用深度集成（仅预留开放接口）。

## 3. 目标用户与使用场景

### 3.1 用户画像
| 角色 | 描述 | 核心诉求 |
| --- | --- | --- |
| 个人用户 | 独立工作者、学生、自由职业者 | 快速记录待办、设置截止日期、获得提醒 |
| 团队负责人 | 3–20 人小团队的管理者 | 分配任务、查看进度、识别阻塞 |
| 团队成员 | 小团队中的执行者 | 查看我的任务、更新状态、避免遗漏 |

### 3.2 核心使用场景
1. **个人晨间规划**：早上 10 分钟内创建当日任务清单并设置优先级。
2. **项目看板跟踪**：负责人按"待办/进行中/已完成"三列跟踪项目进度。
3. **截止提醒**：任务到期前收到提醒，避免遗忘重要交付。
4. **周报汇总**：一键查看本周完成/未完成任务，生成简要统计。

## 4. 产品概述

### 4.1 产品定位
一款轻量、直观的**任务管理 Web 应用**（暂定名：TaskFlow），面向个人与小型团队，聚焦"创建—分配—跟踪—完成"闭环。

### 4.2 平台与形态
- 形态：响应式 Web 应用（桌面优先，兼容移动端浏览器）。
- 技术栈建议：前端 React + 后端 Node.js（或同类），数据库 PostgreSQL，部署于云端。

### 4.3 核心功能总览
| 模块 | 说明 | 优先级 |
| --- | --- | --- |
| 任务管理 | 创建、编辑、删除、完成、复制任务 | P0 |
| 任务属性 | 标题、描述、负责人、截止日期、优先级、标签 | P0 |
| 看板视图 | 按状态分列的看板拖拽操作 | P0 |
| 列表视图 | 可排序、可筛选的任务列表 | P0 |
| 筛选与搜索 | 按负责人/标签/优先级/截止日期筛选，关键词搜索 | P1 |
| 提醒通知 | 站内 + 邮件提醒（到期前 N 小时） | P1 |
| 项目管理 | 将任务归入项目，项目级汇总 | P1 |
| 统计报表 | 完成率、逾期率等基础统计 | P2 |
| 团队与权限 | 创建团队、邀请成员、角色权限 | P1 |

## 5. 功能需求

### 5.1 任务管理（P0）
- **FR-01 创建任务**：用户可创建任务，必填项仅"标题"，其余字段可选。
- **FR-02 编辑任务**：可修改标题、描述、负责人、截止日期、优先级、标签。
- **FR-03 完成任务**：一键标记完成；已完成任务进入归档视图，可恢复。
- **FR-04 删除任务**：删除需二次确认；删除后进入回收站（保留 30 天）。
- **FR-05 复制任务**：复制任务及其属性，生成新任务。

### 5.2 视图（P0）
- **FR-06 看板视图**：按状态（待办/进行中/已完成）分列展示，支持拖拽改变状态。
- **FR-07 列表视图**：表格/列表展示，支持按截止日期、优先级、负责人排序。
- **FR-08 视图切换**：同一项目内可随时切换看板/列表视图，状态实时同步。

### 5.3 筛选与搜索（P1）
- **FR-09 多维筛选**：支持按负责人、标签、优先级、截止日期范围组合筛选。
- **FR-10 关键词搜索**：标题与描述支持模糊搜索，结果高亮。

### 5.4 提醒与通知（P1）
- **FR-11 到期提醒**：任务到期前 24 小时/1 小时发送站内提醒；开启邮件后同步邮件提醒。
- **FR-12 通知中心**：站内通知列表，未读数角标。

### 5.5 项目与团队（P1）
- **FR-13 项目管理**：创建项目，任务归属项目；项目内提供汇总统计。
- **FR-14 团队管理**：创建团队、邀请成员（邮箱邀请）、成员角色（所有者/管理员/成员）。
- **FR-15 权限控制**：成员默认可查看项目全部任务；仅管理员可删除项目。

### 5.6 统计报表（P2）
- **FR-16 基础统计**：项目/个人维度展示任务总数、完成率、逾期率、本周趋势。

### 5.7 账号与数据（P0）
- **FR-17 账号体系**：支持邮箱注册登录、第三方登录（Google/GitHub，P1）。
- **FR-18 数据导出**：任务数据支持导出为 CSV（P2）。
