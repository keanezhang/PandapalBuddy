## ASCII 功能树绘制规范

**核心字符集**：
| 字符 | 用途 | 字符 | 用途 |
|------|------|------|------|
| `┌` `┐` `└` `┘` | 单线框四角 | `╔` `╗` `╚` `╝` | 双线框四角（阶段标题可选） |
| `─` | 横线 | `│` | 竖线 |
| `├` `┤` | 竖向分支 | `┬` `┴` | 横向分支 |
| `┼` | 十字交叉 | `▼` `►` `◄` | 方向箭头 |
| `......` | 省略占位 | | |

**绘制步骤**：
1. **先统计**：L1 域数、每个域的 L2 数、每个 L2 的 L3 数，确定画布宽度和深度
2. **自上而下**：L0 居中 → L1 均分宽度 → L2 在父域内居中 → L3 对齐父模块
3. **先画框再连线**：每个节点先画 `┌──┐` 框 + 内部文字，再画竖线 `│` 和横线 `─` 连接
4. **分支用 `├` `┤` `┬` `┴`**：一个父节点分叉到多个子节点时使用
5. **层级标注**：在右侧用 `◄ L0` `◄ L1` 等标注层级
6. **外部依赖**：用普通框 + 文字 `外部：XXX` 标注，放在图的右下方
7. **整体包裹**：整个图用 ` ```text ` 和 ` ``` ` 包裹

**对齐要点**：
- 每个中文字符占 2 个英文字符宽度，ASCII 制表符占 1 个宽度
- 框内文字 + 两侧空格 + 边框共 = 框宽，框宽为偶数
- L0 框约 26-30 字符宽，L1 框约 16-20 字符宽，L2 框约 14-16 字符宽，L3 框约 10-12 字符宽
- 竖线从父框底部中心 `┴` 出发，到子框顶部中心 `┬` 汇入


## ASCII 数据流图绘制规范

**核心字符集**：
| 字符 | 用途 |
|------|------|
| `┌─┐│└┘` | 节点框 |
| `─` `→` `►` | 横向流转箭头 |
| `│` `▼` | 纵向流转箭头 |
| `┌` `└` | 分支/汇合 |

**绘制规则**：
1. **节点框**：横向链路用 `┌──────┐` 框，一行排列 2~4 个节点
2. **流转箭头**：框之间用 `── 动作描述 ──►` 连接，动作描述用 4-10 个中文/英文
3. **纵向分支**：从框的底部 `└──┘` 向下引出竖线 `│` + `▼`，连接异常/分支路径
4. **异常路径**：用 `▼` 向下引出异常处理节点，虚线效果用文字 `<异常>` 标注替代
5. **回流箭头**：从底部节点用 `└── 重新触发 ──┘` 回到上方节点
6. **整体包裹**：整个图用 ` ```text ` 和 ` ``` ` 包裹

**链路数量**：
- 【中等】至少 1 条核心链路图
- 【复杂】至少 2 条核心链路图（不同角色或用例各一条）

### 3.2 业务链路

#### 核心链路 1：任务创建与流转

```text
┌──────────┐  填写并提交  ┌──────────┐  指派成员   ┌──────────┐   状态变更   ┌──────────┐
│ 成员在看板 │ ────────────►│ 任务创建  │ ──────────►│ 任务进入   │ ───────────►│ 任务推进  │
│ 页点击新建 │             │ 表单     │            │ 待处理列  │             │ 至完成   │
└──────────┘              └────┬─────┘            └────┬─────┘             └────┬─────┘
                              │                        │                       │
                              │ <校验失败: 标题为空/     │ <指派非项目成员>       │ 输出
                              │  项目已归档>            ▼                       ▼
                              ▼                  ┌──────────┐            ┌──────────┐
                        ┌──────────┐             │ 提示并回退 │            │ 通知相关  │
                        │ 表单报错  │             └──────────┘            │ 成员     │
                        └──────────┘                                      └──────────┘
```

**链路说明**：成员在看板页新建任务 → 提交表单（校验项目未归档、标题非空）→ 任务进入「待处理」列并指派给项目内成员 → 成员推进任务状态（待处理→进行中→已完成）→ 每次状态变更向相关成员（创建人、指派人、关注人）发送通知。

#### 核心链路 2：项目创建与成员加入

```text
┌──────────┐  创建项目   ┌──────────┐  邀请成员  ┌──────────┐  接受邀请  ┌──────────┐
│ 管理员在  │ ───────────►│ 项目创建  │ ─────────►│ 成员邀请  │ ─────────►│ 成员进入  │
│ 项目列表页 │            │ 完成     │           │ 发出     │           │ 项目     │
└──────────┘             └────┬─────┘           └────┬─────┘           └────┬─────┘
                             │                      │                       │
                             │ <管理员校验: 项目名   │ <邀请发送失败>         │ 输出
                             │  重复>               ▼                       ▼
                             ▼               ┌──────────┐            ┌──────────┐
                       ┌──────────┐          │ 提示重试  │            │ 首次进入  │
                       │ 表单报错  │          └──────────┘            │ 看板空状态│
                       └──────────┘                                   └──────────┘
```

**链路说明**：管理员创建项目（校验项目名唯一）→ 在成员管理页邀请成员（通过邮箱/链接，默认角色普通成员）→ 成员接受邀请后进入项目 → 首次进入看到看板空状态引导 → 管理员可随时调整成员角色或移除成员。

### 3.3 状态流转

#### 任务状态机

```text
      ┌──────────┐  指派并开始  ┌──────────┐   标记完成   ┌──────────┐
 ────►│  待处理   │ ───────────►│  进行中   │ ───────────►│  已完成   │
      └──────────┘             └─────┬────┘              └──────────┘
            ▲                        │
            │   重新打开             │ 取消任务
            │                        ▼
            │                  ┌──────────┐
            └──────────────────│  已取消   │
                               └──────────┘
```

##### 状态定义

| 状态 | 含义 | 允许的下一状态 | 触发迁移的动作/条件 |
|------|------|---------------|-------------------|
| 待处理 | 任务已创建，尚未开始 | 进行中, 已取消 | 成员点击「开始」；创建人/管理员取消 |
| 进行中 | 任务正在被执行 | 已完成, 已取消, 待处理 | 成员标记完成；取消；拖回待处理 |
| 已完成 | 任务交付验收通过 | 待处理 | 成员/管理员「重新打开」 |
| 已取消 | 任务被终止，不再推进 | 待处理 | 创建人/管理员「重新打开」 |

##### 非法迁移

| 从 | 到 | 拒绝原因 | 系统行为 |
|----|-----|---------|---------|
| 待处理 | 已完成 | 未开始的任务不可直接标记完成 | 拒绝并提示「请先将任务置为进行中」 |
| 已完成 | 已取消 | 已完成的交付物不可直接取消 | 拒绝并提示「请先重新打开任务」 |
| 已取消 | 已完成 | 已取消任务不可直接完成 | 拒绝并提示「请先重新打开任务」 |
