## 1. 产品概述

### 1.1 产品定位
面向连锁奶茶店的一套会员积分管理系统，覆盖"顾客消费累积积分—积分兑换权益"的完整闭环，并为店长提供本店的积分发放/兑换查询与规则配置能力。

### 1.2 产品背景
公司为连锁奶茶品牌，拥有多家直营/加盟门店。目前缺乏统一的会员与积分体系：
- 顾客消费无积分激励，复购率与客单价提升空间大；
- 各门店积分规则不一，难以统一运营；
- 店长无法查看本店积分收支情况，缺乏数据抓手；
- 总部缺少会员运营与营销的数据基础。

### 1.3 产品目标
1. 建立统一的会员积分账户体系，实现"1 元 = 1 积分"等标准化规则；
2. 打通门店收银与积分发放，顾客消费即累积积分，降低运营成本；
3. 提供积分兑换（饮品 / 优惠券）能力，提升会员活跃与复购；
4. 店长可查看本店积分发放/兑换报表并配置本店积分规则；
5. 为后续会员精细化运营（等级、券营销）奠定数据基础。

### 1.4 核心衡量指标
| 指标 | 说明 | 目标（上线后 6 个月） |
| --- | --- | --- |
| 会员注册率 | 到店消费顾客中注册会员占比 | ≥ 40% |
| 积分参与率 | 注册会员中产生积分行为的占比 | ≥ 60% |
| 积分兑换率 | 已发放积分中被兑换的比例 | ≥ 25% |
| 会员复购率 | 90 天内有 ≥2 次消费的会员占比 | 环比提升 10% |
| 兑换核销率 | 已兑换权益被实际使用的比例 | ≥ 70% |

## 2. 目标用户与使用场景

### 2.1 用户角色
| 角色 | 说明 | 核心诉求 |
| --- | --- | --- |
| 顾客（会员） | 到店消费的普通消费者 | 方便地累积与查询积分，快速兑换权益 |
| 店长 | 单店经营管理者 | 掌握本店积分收支，自主设置积分规则 |
| 收银员 | 门店前台操作人员 | 收银时快速完成积分发放/核销 |
| 总部运营/管理员 | 品牌总部人员 | 全局规则配置、门店管理、数据看板 |

### 2.2 典型使用场景
1. **消费累积**：顾客到店购买 25 元饮品，收银员结账时录入会员手机号，系统按规则自动发放 25 积分。
2. **积分查询**：顾客在会员小程序查看当前积分余额与收支明细。
3. **积分兑换**：顾客用 300 积分兑换一杯指定饮品券，或 500 积分兑换 5 元优惠券。
4. **门店管理**：店长在后台查看本店当日/当月发放积分、兑换积分、核销情况，并调整本店积分倍数（如营销活动期间 1 元 = 2 积分）。
5. **总部运营**：管理员新增可兑换商品、设置全局默认积分规则、查看各门店积分数据排行。

## 4. 功能需求

### 4.1 顾客端（会员小程序 / H5）

#### FR-1 会员注册与登录
- 支持手机号 + 短信验证码注册/登录；首次注册即自动创建会员账户。
- 支持绑定微信（openid），绑定后可一键登录。
- 同一手机号全局唯一，一个会员账户。

#### FR-2 会员卡展示
- 展示会员卡号、当前积分余额、累计获得积分。
- 展示当前积分规则（如 1 元 = 1 积分）与积分有效期提示。

#### FR-3 积分明细
- 按时间倒序展示积分流水：时间、类型（获得/消耗/调整/过期）、数值（±）、关联订单或商品、备注。
- 支持按类型筛选、按月筛选。

#### FR-4 积分兑换
- 展示可兑换商品列表（饮品券、优惠券），含所需积分、库存（如有）、适用门店范围、有效期。
- 兑换操作：确认兑换 → 二次确认（消耗积分提示）→ 生成兑换码/券。
- 积分不足时给出提示并引导"如何赚积分"。
- 兑换成功后可查看我的券/兑换记录，券支持到店核销。

#### FR-5 消息通知
- 积分发放、积分即将过期、兑换成功等关键事件通过站内消息/微信模板消息通知（MVP 可先做站内消息）。

### 4.2 门店端（店长 / 收银员，Web 后台 + 收银台）

#### FR-6 收银积分操作
- 收银结账时输入会员手机号/扫码，系统按规则自动计算并发放积分，收银小票展示本次获得积分。
- 支持收银员手动备注调整（如补发、撤销当日错发），需店长权限或留痕。

#### FR-7 兑换核销
- 顾客出示兑换码/券码，收银员输入或扫码核销，核销后券状态置为"已使用"。
- 支持查询券码有效性、防止重复核销。

#### FR-8 积分规则设置（店长）
- 可查看并修改本店积分规则，主要包括：
  - 积分获取比例（默认 1 元 = 1 积分，可配置为 1 元 = N 积分）；
  - 是否按支付金额取整/四舍五入；
  - 单笔积分上限（防刷）；
  - 积分有效期策略（默认长期有效，可选 1 年）；
  - 特殊商品是否参与积分（如特价饮品不积分）。
- 修改规则需经总部审批或留痕（MVP 可先直接生效并记录操作日志，后续加审批）。

#### FR-9 本店积分报表（店长）
- 今日/本周/本月维度：
  - 发放积分总数与笔数、兑换积分总数与笔数、核销券数；
  - 积分发放 TOP 商品、兑换 TOP 商品；
  - 环比趋势图。
- 支持按日期范围筛选与导出（Excel）。

### 4.3 管理后台（总部运营/管理员）

#### FR-12 全局积分规则
- 设置全品牌默认积分比例（1 元 = 1 积分）、积分有效期、单笔上限等。

#### FR-14 数据看板

## 5. 积分规则

### 5.1 积分获取
| 规则项 | 默认值 | 说明 |
| --- | --- | --- |
| 获取比例 | 1 元 = 1 积分 | 按实付金额计算（扣除优惠券抵扣部分，MVP 按实付计） |
| 计算方式 | 向下取整 | 25.6 元 → 25 积分（可配置四舍五入） |
| 单笔上限 | 500 积分 | 防大额异常订单刷分 |
| 积分有效期 | 长期有效 | 可配置为自获得之日起 1 年 |
| 不参与商品 | 特价/秒杀商品 | 由门店在规则中配置 |

### 5.2 积分使用
| 规则项 | 说明 |
| --- | --- |
| 兑换比例 | 由总部/门店在兑换商品中定义（如 300 积分 = 1 杯饮品券） |
| 兑换限制 | 单日兑换次数上限（默认 5 次）、单商品每日兑换上限 |
| 积分不足 | 兑换前校验余额，不足则拦截并提示 |
| 撤销 | 券过期未核销可退回积分（按商品规则决定是否退回） |
| 过期积分 | 到期前 30 天提醒；过期积分从余额扣减并记录流水 |

### 5.3 风控规则
- 单账号高频兑换、批量注册小号薅积分等异常行为触发风控告警；
- 积分调整操作全部留痕，支持审计追溯；
- 每日积分发放/兑换异常波动（如超门店日均 5 倍）推送告警给总部。

## 6. 核心业务流程

### 6.1 消费累积积分流程
```
顾客点单 → 收银台结账 → 录入会员（手机号/扫码）
  → 系统校验会员有效性 → 按规则计算积分 → 发放积分并记流水
  → 小票展示"本次获得 XX 积分" → 顾客端同步收到积分到账通知
```

### 6.2 积分兑换流程
```
顾客在小程序选择商品 → 校验积分余额与库存 → 二次确认兑换
  → 扣减积分、生成兑换码/券 → 顾客到店出示码
  → 收银员核销 → 券状态置为已使用 → 记录核销流水（计入店长报表）
```

### 6.3 规则设置流程
```
店长进入门店设置 → 修改积分规则 → 保存（记录操作日志）
  → 新规则即时生效 → 后续订单按新规则计算
```

| 积分规则（points_rule） | 规则ID、门店ID（空为全局）、获取比例、计算方式、单笔上限、有效期策略、生效时间 |
| 兑换商品（redeem_item） | 商品ID、名称、类型（饮品券/优惠券）、所需积分、适用门店、库存、有效期、上下架状态 |
| 兑换记录（redeem_order） | 兑换单ID、会员ID、商品ID、消耗积分、券码、状态（待核销/已核销/已过期/已退回）、时间 |
| 门店（store） | 门店ID、名称、地址、状态 |
| 用户账号（account） | 账号ID、姓名、手机号、角色、绑定门店ID |

## 10. 埋点与统计
- 埋点：注册、登录、查看积分、查看明细、查看商城、发起兑换、兑换成功、核销、规则修改。
- 报表：会员增长曲线、积分发放/兑换趋势、兑换商品热度、门店积分运营排行。

## 12. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 积分规则被恶意刷分 | 财务损失 | 单笔上限、风控告警、异常冻结 |
| 收银系统对接延迟 | 积分发放不准 | 幂等设计、对账任务、人工补发工具 |
| 店长随意改规则 | 品牌规则混乱 | 操作留痕 + 后续加总部审批流 |
| 积分兑换引发客诉 | 客户流失 | 明确规则公示、客服话术、过期提醒 |
| 数据安全合规 | 法律风险 | 加密存储、最小权限、隐私协议 |
