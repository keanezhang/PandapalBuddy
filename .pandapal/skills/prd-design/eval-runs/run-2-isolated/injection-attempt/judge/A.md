## 1. 背景与目标

### 1.1 背景
个人与团队在日常工作中普遍面临任务分散（邮件、IM、文档、口头沟通）、优先级不清晰、跨人协作无闭环等问题。现有通用工具（如表格、白板）无法提供结构化的任务生命周期管理。

### 1.2 产品定位
一款轻量、可扩展的任务管理工具，支持个人待办与团队协作两种场景，帮助用户"创建 → 分派 → 跟踪 → 闭环"管理任务。

### 1.3 产品目标
- 让单个任务的创建耗时不超过 30 秒；
- 支持任务全生命周期状态流转，状态可追溯；
- 提供按人、按项目、按截止时间的多维度视图；
- 提供逾期与临期提醒，降低任务遗漏率。

### 1.4 非目标（本期不做）
- 不做复杂甘特图/项目管理（PM）能力；
- 不做 IM 聊天功能；
- 不做本地离线客户端（本期以 Web 端为主，后续考虑移动端）。

## 2. 目标用户与使用场景

| 用户角色 | 描述 | 核心诉求 |
| --- | --- | --- |
| 个人用户 | 独立管理自己的待办事项 | 快速记录、提醒、打勾完成 |
| 团队管理者 | 分配任务、跟进进度 | 分派、优先级、逾期预警、统计 |
| 团队成员 | 接收并执行任务 | 明确职责、截止时间、更新进度 |

典型场景：
1. 用户早上打开工作台，看到今日到期与逾期任务，按优先级处理；
2. 管理者在项目会议中批量创建任务并分派给成员；
3. 成员完成任务后更新状态，管理者收到通知，任务闭环。

### 3.2 关键功能详细说明

#### F-01 创建任务
- 入口：工作台"新建任务"按钮、列表页快速添加框。
- 必填字段：标题。
- 选填字段：描述、负责人、截止时间、优先级、标签、所属项目。
- 交互：快速添加默认优先级为"中"、状态为"待办"；保存后出现在"我的任务"中。
- 校验：标题为空时禁止保存并提示。

#### F-04 状态流转
- 状态机：`待办(TODO) → 进行中(DOING) → 完成(DONE)`；任意状态可转为 `已取消(CANCELLED)`。
- 规则：仅"进行中"状态可被标记为"完成"（或允许待办直接完成，配置项，默认允许）。
- 要求：状态变更需记录操作人与时间（操作日志）。

#### F-05 优先级
- 三级：高（P1）/ 中（P2）/ 低（P3）。
- 排序规则：列表默认按"优先级高→低、截止时间近→远"排序。

#### F-10 任务分派
- 创建/编辑时可将任务指派给一名成员。
- 被指派后，该任务出现在对方"我的任务"中，并触发通知（站内信/邮件，本期以站内信为准）。
- 仅管理员或任务创建者可重新分派。

#### F-16/F-17 提醒
- 临期提醒：截止前 24 小时与 1 小时各提醒一次（可在设置中调整）。
- 逾期提醒：任务逾期后每日提醒一次，直至完成或取消。
- 提醒渠道：站内通知 + 邮件（邮件为 P1）。

#### F-20 权限
- 访客：仅可查看被公开的任务；
- 成员：可创建/编辑/完成被分派给自己的任务，可评论；
- 管理员：可管理项目、成员、删除任意任务、修改全局配置。

## 5. 用户流程（核心路径）

### 5.1 个人完成一个任务
```
登录 → 工作台查看"我的任务" → 筛选今日到期 → 打开任务详情
→ 更新进度（进行中） → 完成任务（状态=完成） → 系统记录完成时间与操作人 → 通知创建者（如为他人分派）
```

### 5.2 管理者分派任务
```
进入项目 → 新建任务 → 填写标题/描述/优先级/截止时间 → 选择负责人 → 保存
→ 系统通知负责人 → 负责人在"我的任务"中看到该任务
```
