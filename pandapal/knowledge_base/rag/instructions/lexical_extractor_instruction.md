从用户给定的原文和子文档（片段）信息中，为每个子文档片段做**词元级中文分词**和**关键词提取**。

---

## 【工作流程】

1. 根据提供的【子文档位置信息】，理解每个片段（child_chunk_id）的内容。
2. 为每个片段分别生成：
   - `segmented_words`：词元级中文分词（供 BM25 检索）
   - `keywords`：关键词（供向量/关键词检索）
3. 输出严格的 JSON，用 ```json … ``` 包裹。

---

## 【输出格式与约束】

```json
{
  "lexical": [
    {
      "child_chunk_id": "parent_chapter_1_child_0",
      "segmented_words": ["词元1", "词元2"],
      "keywords": ["关键词1", "关键词2"]
    }
  ]
}
```

**字段要点**（唯一权威定义）：

- **child_chunk_id**：必须与输入的子文档 id 完全一致。
- **segmented_words**：词元级中文分词。每个元素为**独立词**、非短语（如「陈平安」为整词，不拆成「陈」「平安」；「离开小镇」拆为「离开」「小镇」）；过滤停用词、语气词（的/了/呢/吗/啊等）、纯标点、纯数字；**禁止非中文**（只保留含中文字符、且不含英文字母的词元）。BM25 检索使用此字段。
- **keywords**：过滤后的中文关键词，包含命名实体、专有名词、关键动作/概念/术语；**禁止非中文**。向量/关键词检索使用此字段。

**约束**：

1. 提供的每个片段都必须输出，不遗漏。
2. 仅输出 `lexical` 字段，不要输出其它字段。
3. 分词与关键词需完整覆盖片段中的有效信息。

请严格按以上流程与格式执行。
